## Цель работы

Закрепить работу с пользователями, группами и правами доступа Linux: создать отдельного пользователя и группу, настроить общий каталог, проверить права на создание/удаление файлов, разобраться в различиях `su` и `sudo`, а также настроить постоянные `alias` и переменную окружения через `~/.bashrc`.

- проверено, почему возможность удалить файл определяется правами каталога;

- объяснено, почему прямой вход под `root` в Ubuntu обычно заблокирован;
- добавлены постоянные `alias` и переменная `COURSE_ENV` в `~/.bashrc`.

## Ключевые команды

```bash
sudo groupadd developers
sudo useradd -m -s /bin/bash -G developers student2
sudo mkdir /srv/shared
sudo chown root:developers /srv/shared
sudo chmod 2775 /srv/shared
ls -ld /srv/shared
```

## Главный вывод

Права на содержимое файла и права на операции с самим файлом — разные вещи: чтение/запись содержимого задаются правами файла, а создание и удаление файлов зависят прежде всего от прав каталога. `sudo` удобнее и безопаснее постоянной работы через `su`, потому что повышает привилегии только для конкретной команды и оставляет аудит действий.
